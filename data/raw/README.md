# Raw Data

압축해제한 원본 데이터셋을 보관하는 곳입니다.

원본 데이터셋은 저장소에 포함하지 않습니다.  
각 데이터셋의 사용 방법은 `docs/datasets/`의 문서를 참고합니다.

<br>

## 폴더 구조

```text
raw/
├─ README.md
├─ flaws-cloudtrail/
│  ├─ flaws_cloudtrail00.json
│  ├─ flaws_cloudtrail01.json
│  ├─ flaws_cloudtrail02.json
│  └─ ...
└─ <추가예정>/
   └─ <추가예정>
```
