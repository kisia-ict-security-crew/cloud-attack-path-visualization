# Data Archives

사용한 공개 데이터셋 원본 압출파일을 보관하는 곳입니다.

원본 데이터셋은 저장소에 포함하지 않습니다.  
각 데이터셋의 다운로드 위치와 준비 방법은 `docs/datasets/`의 문서를 참고합니다.

<br>

## 폴더 구조

```text
archives/
├─ README.md
├─ flaws_cloudtrail_logs/
│  ├─ flaws_cloudtrail00.json.gz
│  ├─ flaws_cloudtrail01.json.gz
│  └─ ...
└─ <추가예정>/
   └─ <추가예정>
```
